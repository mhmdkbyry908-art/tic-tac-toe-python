# 🎮 Tic-Tac-Toe — Python

A console-based Tic-Tac-Toe game built with **Python** using **Object-Oriented Programming (OOP)** principles.

The project includes multiple game modes and three AI difficulty levels, including a **Minimax-based Hard AI**.

## 🚀 Features

* 🎮 Human vs AI
* 👥 Human vs Human
* 🟢 Easy AI — Random moves
* 🟡 Medium AI — Winning and defensive moves
* 🔴 Hard AI — Minimax algorithm
* 📐 Custom board size
* 🏆 Win and draw detection
* ⌨️ Input validation
* 🧱 Object-Oriented Programming structure

## 🧠 AI Difficulty Levels

### Easy

The AI chooses an available cell randomly.

### Medium

The AI:

* Looks for a winning move
* Blocks the opponent's winning move
* Otherwise makes a random move

### Hard

The AI uses the **Minimax algorithm** to evaluate possible moves and choose the best available move.

> Hard AI is designed for a standard 3×3 Tic-Tac-Toe board. Larger boards can require significantly more computation because of the Minimax search.

## ▶️ How to Run

Make sure Python 3 is installed.

Clone the repository:

```bash
git clone https://github.com/mhmdkbyry908-art/tic-tac-toe-python.git
```

Enter the project folder:

```bash
cd tic-tac-toe-python
```

Run the game:

```bash
python main.py
```

## 🎯 Game Modes

When the game starts, you can choose:

```text
1) Human vs AI
2) Human vs Human
```

If you choose Human vs AI, you can select:

```text
easy
medium
hard
```
